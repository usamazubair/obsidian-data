### 2. Use SWC instead of the default TypeScript compiler

NestJS officially recommends SWC for significantly faster development compilation.

Install it:

```
npm install --save-dev @swc/core @swc/cli
```

Test it:

```
npx nest start --watch --builder swc
```

Update `package.json`:

```
{
  "scripts": {
    "start:dev": "nest start --watch --builder swc"
  }
}
```

Then use:

```
npm run start:dev
```

This is likely to produce the biggest NestJS compilation improvement after fixing the project location.
