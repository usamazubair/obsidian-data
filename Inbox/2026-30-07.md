Here are the basic `tmux` commands you need.

## Start a new session

```
tmux new -s ebm-push
```

## Run your script inside tmux

```
bash ./push-ebm-routes-1.sh
```

## Detach and leave it running

Press:

```
Ctrl+B
```

Release, then press:

```
D
```

This exits the tmux view but keeps the script running.

## List sessions

```
tmux ls
```

Example:

```
ebm-push: 1 windows
```

## Reopen the session

```
tmux attach -t ebm-push
```

Short form:

```
tmux a -t ebm-push
```

## Check output without entering

```
tmux capture-pane -t ebm-push -p | tail -100
```

## Stop the running script

First attach:

```
tmux attach -t ebm-push
```

Then press:

```
Ctrl+C
```

This stops the Bash script.

## Exit the tmux session normally

After the script stops, type:

```
exit
```

This closes the tmux session.

## Completely kill a session from outside

```
tmux kill-session -t ebm-push
```

This stops the session and any process running inside it.
