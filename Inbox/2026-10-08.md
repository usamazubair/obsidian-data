Here's the full setup, start to finish:

**1. Install nodemon as a dev dependency**

bash

```bash
npm install --save-dev nodemon
```

**2. Create a `nodemon.json`** in your project root (same level as `package.json`):

json

```json
{
  "watch": ["src", ".env"],
  "ext": "ts,js,json,env",
  "ignore": ["dist", "node_modules", "*.spec.ts"],
  "exec": "nest start"
}
```

- `watch` — folders/files nodemon monitors for changes
- `ext` — file extensions that count as a trigger
- `exec` — the command nodemon runs on start and re-runs on every restart

**3. Add a script in `package.json`:**

json

```json
"scripts": {
  "start:dev": "nodemon"
}
```

(nodemon automatically reads `nodemon.json` from the project root — no need to pass flags.)

**4. Run it:**

bash

```bash
npm run start:dev
```

You'll see nodemon boot your NestJS app via `nest start`. Now:

- Edit any `.ts` file in `src` → nodemon restarts automatically
- Edit `.env` → nodemon restarts automatically too, since it's in the watch list

**A few things worth knowing:**

- **Manual restart anytime:** while it's running, type `rs` and hit Enter in the same terminal — forces a restart without waiting for a file change.
- **Restart delay:** if it feels like it restarts too eagerly on rapid saves, add `"delay": "1000"` (ms) to `nodemon.json` to debounce.
- **Nest's `--watch` vs nodemon:** don't run both at once (`nest start --watch` _and_ nodemon) — that double-watches and can cause restart loops. Use nodemon as your only watcher when you go this route.
- **Ctrl+C** stops nodemon and the app together, same as any normal dev server.
